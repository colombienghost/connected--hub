# CONNECTED Brand Guidelines

## Positionnement

CONNECTED est une application premium de livraison de colis entre particuliers, basee sur des voyageurs verifies. La marque doit inspirer confiance, clarte et mobilite internationale.

Promesse principale:
**Envoyer moins cher avec des voyageurs verifies.**

Ton de marque:
- Clair, rassurant, humain.
- Premium sans froideur.
- Direct dans les actions: envoyer, suivre, verifier, reserver.
- International, mais proche de l'utilisateur.

## Logo

Le symbole central associe trois idees:
- une valise pour le voyage et la capacite bagage;
- un avion pour la route internationale;
- une forme simple et memorisable pour l'usage mobile.

Usage recommande:
- logo complet `CONNECTED` pour onboarding, page d'accueil, reseaux sociaux;
- pictogramme seul pour icone app, badges, splash screen, favicon;
- version blanche sur fond navy;
- version navy sur fond warm white;
- version navy sur fond amber uniquement pour accents ou campagnes.

A eviter:
- deformer la valise;
- ajouter trop de details dans l'avion;
- utiliser le logo sur fonds tres charges;
- remplacer CONNECTED par une autre marque dans l'interface.

## Couleurs

| Role | Couleur | Hex | Usage |
| --- | --- | --- | --- |
| Primary Navy | Bleu profond | `#06254F` | headers, navigation, fonds premium, textes forts |
| Warm White | Blanc chaud | `#FAFBFD` | fonds principaux, cartes, carrousels clairs |
| Amber Action | Ambre | `#FFB000` | CTA, prix, progression, accents de confiance |
| Sky Soft | Bleu ciel pale | `#D6E8F7` | surfaces secondaires, badges, illustrations |
| Cool Gray | Gris froid | `#E9EDF3` | bordures, separations, fonds neutres |
| Charcoal | Noir doux | `#101820` | traits d'illustration, texte tres contraste |

Ratio recommande:
- Interface app: 60% warm white, 25% navy, 10% sky/cool gray, 5% amber.
- Instagram sombre: 70% navy, 20% white, 10% amber/sky.
- Instagram clair: 70% warm white, 20% navy, 10% amber/sky.

## Typographie

Direction recommandee:
- Titres marketing: serif premium ou display elegante, proche de Playfair Display.
- Interface et textes courants: sans-serif moderne, proche de Inter.

Regles:
- Dans l'app, priorite a la lisibilite: titres courts, labels directs, chiffres tres lisibles.
- Sur Instagram, le contraste peut etre plus editorial: grands titres, peu de texte, visuels respirants.
- Pas de letter-spacing negatif.

## Illustration

Style valide:
- personnages allonges;
- traits fins navy ou charcoal;
- aplats simples amber, sky, navy, blanc;
- visages minimaux;
- objets clairs: valise, colis, telephone, passeport, carte, avion;
- leger grain papier autorise pour les visuels marketing.

Usage dans l'app:
- onboarding: illustration dominante;
- inscription: une illustration par etape;
- accueil: petites illustrations d'accompagnement;
- resultats, paiement, suivi: illustrations discretes pour garder l'interface efficace;
- empty states et confirmations: illustration plus visible.

A eviter:
- illustrations trop enfantines;
- personnages trop realistes;
- scenes surchargees;
- couleurs hors systeme.

## UI Mobile

Structure recommandee:
- header navy avec logo ou titre;
- cartes blanches sur fond warm white;
- CTA principal amber;
- CTA secondaire navy ou outline;
- badges de confiance en sky;
- bottom navigation navy, icone active amber.

Composants prioritaires MVP:
- carte trajet;
- carte voyageur verifie;
- bouton `Trouver un voyageur`;
- bouton `Envoyer un colis`;
- badge `Verifie`;
- statut `Paiement protege`;
- timeline de suivi;
- module route depart -> arrivee;
- choix role `Expediteur` / `Convoyeur`.

## Reseaux Sociaux

Systeme recommande:
- alternance dark / light pour les carrousels;
- dark pour couvertures, preuves, annonces fortes;
- light pour tutoriels, explications, comparaisons;
- grand titre, une idee par slide;
- logo petit mais constant;
- illustrations humaines pour rendre la tech accessible.

Templates utiles:
- Cover: `CONNECTED` + promesse.
- Tutoriel: 3 etapes simples.
- Trust: voyageurs verifies, paiement protege, suivi.
- Route: ville depart -> ville arrivee.
- CTA: rejoindre, envoyer, devenir voyageur.

## Direction MVP

Le MVP doit d'abord livrer ces parcours:
1. Onboarding.
2. Connexion / inscription par slides.
3. Accueil expediteur.
4. Recherche de voyageurs.
5. Detail voyageur / trajet.
6. Reservation colis.
7. Paiement protege.
8. Chat.
9. Suivi colis.
10. Profil et verification.

Le langage visuel doit rester coherent du premier ecran jusqu'au suivi final: confiance, voyage, simplicite, securite.
